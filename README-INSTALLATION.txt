IRONLOG PWA iOS

1. Publier le contenu de ce dossier sur un hébergement HTTPS, par exemple GitHub Pages.
2. Sur l'iPhone, ouvrir l'URL publique avec Safari.
3. Dans Safari : Partager > Sur l'écran d'accueil > Ajouter.
4. Lancer IronLog depuis l'icône de l'écran d'accueil.

Important : le fichier HTML ouvert directement depuis Fichiers/OneDrive n'est pas l'installation PWA. Le manifest et le service worker sont prévus pour fonctionner depuis une origine web HTTPS.
